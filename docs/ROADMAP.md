# Roadmap

## 0.1 — Public foundation

- One-screen simulator
- Four algorithm modes
- Confidence rails and secure state machine
- Deterministic presets and JSON experiments
- GitHub Pages deployment

## 0.2 — Measurement depth

- Three-phase overlay and symmetrical components
- Improved CT saturation and DC-offset models
- Packet-level event inspector
- Synchronized side-by-side algorithm comparison

## 0.3 — Engineering interoperability

- COMTRADE import and mapping wizard
- Exportable plots and experiment report
- Reference-vector test suite
- URL-shareable experiment configuration

## 1.0 — Validated education release

- External subject-matter review
- Stable experiment schema
- Documented numerical tolerances
- Translation framework
- Published teaching modules and reproducible lab exercises
